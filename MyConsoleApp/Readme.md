
Task : 

Juned is a player who has an initial skill level of M. 
He will face N opponents, each with a skill level of Ai. 
The order in which he faces the opponents can be chosen by Juned. 
After defeating an opponent, Juned gains a skill level of BI.

//M is initial skill
//N is the loop
//Ai is the skill to lawan
//skill order can be selected by player
//Bi is the gained skill

How to run the program:
To run the program, follow these steps:
 1. Open the project in your Visual Studio2026 (or your preferred IDE).
 2. Build the project to ensure all dependencies are resolved.
 3. Run the program using the IDE's run/debug feature or by executing the compiled binary from the command line.
 4. You will be prompted to enter 3 times  
	a. On first prompt enter 2 numbers separated by space as N and M. 
	   The first number (N) represents the number of opponents, and the second number (M) represents Juned's initial skill level.
	b. On second prompt enter N numbers separated by space => representing the skill levels of the opponents (A1, A2, ..., AN).
	c. On third  prompt enter N numbers separated by space => representing the skill levels gained after defeating each opponent (B1, B2, ..., BN).
	
	Then press Enter to see the result of the simulation, which will display Juned's final skill level after facing all opponents in the optimal order.
